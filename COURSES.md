## Intro to Econometrics with Python

### Grade structure
- Homework: 20%
- Three mini-projects: 15%
- Two exams combined: 30%
- Final project: 35%

### Core learning path
1. Data / variables / distributions
2. Correlation and covariance
3. Simple regression
4. OLS mechanics and interpretation
5. Sampling uncertainty
6. Confidence intervals and t-tests
7. Multiple regression
8. Omitted-variable bias / measurement problems
9. Dummies / interactions / logs
10. Heteroskedasticity
11. Multicollinearity
12. Causal inference / research design
13. Python implementation and interpretation

### AI restriction - strict
AI is allowed for **general study support** such as clarifying concepts or reviewing material, but not for AI-generated homework answers, graded explanations, code for graded work, rewritten/generated final-project text, exams, or other AI contributions to graded assignments/projects.

Operational rule: learn with unrelated practice problems/datasets, then complete assessed work independently.

### Process rule from HW1
Before graded econometrics work: brief textbook/lecture review -> 2-3 independent practice problems -> assessment.

# Cross-course priority rules

1. Imminent graded deadlines outrank generic curriculum order.
2. Seminar, Econometrics final project, and IO project require recurring work; do not defer them to exam season.
3. Use IO as the main applied microeconomics spine this semester.
4. Use Econometrics as the evidence/causality spine.
5. Use Development to connect micro, macro, institutions, policy, and empirical evidence.
6. Use Seminar to practice forming and defending economic arguments.
7. Keep Construction contained with a weekly recurring workflow so it does not become surprise backlog.
8. Reprocess the Canvas .ics feed whenever a fresh export is uploaded; calendar feeds can change as instructors update assignments.
