# Study

Durable memory and operating system for Fall 2026 study.

This repository is **not** a transcript archive. It stores only information that should survive across chats: current course constraints, mastery state, project decisions, teaching methodology, and the next learning path.

## Source of truth

- [`STUDY_SYSTEM.md`](STUDY_SYSTEM.md) - how lessons are scheduled and taught
- [`MASTERY.md`](MASTERY.md) - current economics/math mastery ledger and learning path
- [`COURSES.md`](COURSES.md) - course structure, deadlines, and AI constraints
- [`projects/industrial-organization.md`](projects/industrial-organization.md) - IO research project requirements and current status
- [`CURRENT.md`](CURRENT.md) - short-lived current checkpoint and next actions

## Operating principle

The goal is not to finish chapters. The goal is to make knowledge **retrievable, connected, and usable later**.

The system should optimize for:

1. Course performance now
2. Long-term economics mastery
3. Low executive-function friction
4. Honest understanding rather than answer generation
5. Maintaining work, construction coursework, health/sanity, and discipleship without creating a second full-time job

## Update rule

Update this repo only when something durable changes:

- a concept moves in mastery status
- a course deadline/requirement changes
- a project decision is made
- a recurring learning weakness is discovered
- the study method is deliberately changed

Do **not** store every chat, every practice question, or every temporary thought.
